A 1024×1024 illustrated newspaper front page covering Friday, 20 November 2026,
using the supplied news brief. Original flag, diplomacy, war, market, and justice
illustrations are drawn with Pillow primitives on warm cream paper.

Regenerate with `python3 generate.py`. Requires Pillow and the local DejaVu fonts
in `/usr/share/fonts/truetype/dejavu/`; no network access is used.

The kit's `main.ts` copies `entry.png` to `/output`.
